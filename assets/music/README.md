# Dossier assets/music/

Placez ici vos musiques de fond (.mp3, .wav, .ogg, .m4a, .aac).

## Structure des sous-dossiers

```
assets/music/
├── calme/        ← Piano doux, ambient, méditation
├── inspirant/    ← Orchestre montant, épique, motivant
├── celebration/  ← Joyeux, louange, victoire
├── priere/       ← Choral, contemplatif, liturgique
└── default/      ← Fallback générique
```

## Mapping thème → ambiance

| Thème clé              | Ambiance musicale |
|------------------------|-------------------|
| confiance, amour, paix | calme             |
| foi, espoir, force     | inspirant         |
| victoire, louange      | celebration       |
| prière, adoration      | priere            |
