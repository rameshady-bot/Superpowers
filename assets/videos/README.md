# Dossier assets/videos/

Placez ici vos vidéos de fond (.mp4, .mov, .avi, .mkv, .webm).

## Structure des sous-dossiers

```
assets/videos/
├── nature/       ← Forêt, pluie, rivière, prairie
├── ciel/         ← Coucher de soleil, nuages, étoiles, aurore
├── eau/          ← Océan, lac, cascade, rivière calme
├── lumiere/      ← Lumière dorée, rayons, bougies, vitrail
├── croix/        ← Croix, église, chapelle, vitrail
└── default/      ← Fallback si aucune catégorie ne correspond
```

## Mapping thème → dossier

| Thème clé         | Dossier prioritaire |
|-------------------|---------------------|
| foi, croire       | ciel, lumiere       |
| confiance, dieu   | lumiere, ciel       |
| paix, repos       | eau, nature         |
| espoir, avenir    | ciel, lumiere       |
| force, victoire   | nature, ciel        |
| prière, louange   | lumiere, croix      |
| amour, grâce      | lumiere, nature     |
| épreuve, guérison | eau, nature         |
